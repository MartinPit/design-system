Two identities for one flashcards app

Each system is a complete token layer, a 27-component library with documented states, and a documentation page — built from a different reference card, on its own branch. Same app, two arguments about how it should feel.

Arcana

Cream and ink, one warm gradient, the grammar of an archive card. Swiss, flat, institutional.

How to read a system

Switch to the branch, run the dev server, and open the single documentation page. The sidebar holds Overview, seven Foundations pages, 27 components in five groups, and the accessibility note. Branches are not hosted and never merge.

Plan and decisions: wayfinder/map.md. Card transcription: wayfinder/references/cards.md.
